# 📐 TMJ-Diagnosis 仕様書: キャリブレーション機能とUX自動化

## 1. プロジェクト・機能概要

| 項目 | 詳細 |
| :--- | :--- |
| **プロジェクト名** | **TMJ-Diagnosis** |
| **機能の目的** | 1. ユーザーが手動でスケール（mm/pixel）を設定できるキャリブレーション機能を追加する。<br>2. 画像ロード時に顎関節領域を自動検出し、最適にズーム・中央表示する。<br>3. ズーム後、輪郭抽出を自動実行し、ユーザーの操作（ボタンクリック）を削減する。 |
| **前提** | F-1〜F-7（デュアルウィンドウUI、Wasmによる輪郭抽出基盤）が実装されていること。 |

***

## 2. 機能要件 (F: Functional Requirement)

### F-8: 手動キャリブレーション機能

| 番号 | 要件 | 詳細 | 担当技術 |
| :--- | :--- | :--- | :--- |
| **F-8.1** | UIトリガー | 左右それぞれのキャンバス（編集ウィンドウ）に「スケール校正」ボタンを設置する。 | Next.js (TS) |
| **F-8.2** | 校正モード | ボタン押下で「校正モード」に移行する。モード中は他の操作（パン/ズーム/ベクター編集）を一時的に無効化し、カーソルを十字に変更する。 | Next.js (TS) / Konva |
| **F-8.3** | 基準線描画 | ユーザーが画像上で2点（基準線の始点と終点）をクリックできる。クリックに合わせて線を描画し、ピクセル距離を計算する。 | Konva |
| **F-8.4** | 距離入力 | 2点目クリック後、「この距離（ピクセル距離: xxx px）は何mmですか？」というダイアログを表示する。入力フィールドにはデフォルト値として **`10`** (mm) を設定する。 | Next.js (TS) |
| **F-8.5** | スケール保存 | ユーザーが入力したmm値とピクセル距離から **`mmPerPixel`**（スケール比率）を算出し、Reactの状態（左右それぞれ）に保存する。 | Next.js (TS) |
| **F-8.6** | モード解除 | スケール保存後、自動的に「校正モード」を解除し、基準線を非表示にする。 | Next.js (TS) |

### F-9: 自動ズーム＆自動抽出 (UX向上)

| 番号 | 要件 | 詳細 | 担当技術 |
| :--- | :--- | :--- | :--- |
| **F-9.1** | ROI自動検出 (Wasm) | 画像読み込み時、Rust Wasm側で画像データから主要な関心領域（ROI）、つまり**顎関節（骨構造）のおおよその矩形（BBox）**を検出する。(R-6で実装) | Rust Wasm |
| **F-9.2** | 自動ズーム/パン | Wasm (F-9.1) が返したROI（BBox）がキャンバスの中央に適切な拡大率（例: キャンバス幅の80%程度）で表示されるよう、Konva Stageのスケールとポジションを**自動で調整**する。 | Next.js (TS) / Konva |
| **F-9.3** | 自動輪郭抽出 | 自動ズーム/パン（F-9.2）のアニメーション完了後、ユーザーのボタン押下を待たずに、**自動的にF-3（Wasmによる輪郭抽出）を実行**する。 | Next.js (TS) & Rust Wasm |
| **F-9.4** | 処理フロー | 画像ロード時の処理フローは「1. 画像ロード → 2. WasmでROI検出 → 3. 自動ズーム/パン → 4. Wasmで自動輪郭抽出 → 5. 編集待機」となること。 | Next.js (TS) / Rust Wasm |
| **F-9.5** | 検出失敗時 | WasmがROI検出（F-9.1）に失敗した場合は、自動ズーム/パンは行わず、画像全体を表示する（現在の動作）。自動輪郭抽出（F-9.3）も実行しない。 | Next.js (TS) |

## 3. コーディング要件 (Rust Wasm 拡張)

### R-6: ROI自動検出モジュール

* **API**: `detect_roi(data: Box<[u8]>, width: u32, height: u32) -> String` を新設する。
* **目的**: F-9.1（自動ズーム）のために、画像内の主要な関心領域（顎関節）のおおよその位置を特定する。
* **処理**:
    1. 入力画像データに対し、閾値処理（Otsu法など）を行い、骨領域（高輝度部）を二値化する。
    2. 二値化画像に対し、連結成分ラベリング（または輪郭検出）を実行する。
    3. 最大の連結成分（または最も関心領域に近い特徴を持つ成分）を選択し、そのバウンディングボックス（BBox）を計算する。
* **出力**: 検出したROIの矩形座標（BBox）をJSON文字列で返却する。失敗した場合は空のJSON `{}` を返す。

```json
// 成功時のJSON出力例
{
  "x": 150,
  "y": 100,
  "width": 200,
  "height": 250
}
