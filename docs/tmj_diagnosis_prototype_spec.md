# 📄 TMJ-Diagnosis プロトタイプ仕様書 (Next.js & Rust Wasm) - 2D画像対応版

## 1. プロジェクト概要

* **プロジェクト名**: **TMJ-Diagnosis**
* **目的**: サーバーアップロードなしで、ブラウザ内にて**2Dモノクロ画像**を読み込み、基本的な画像操作機能とWasm連携のテスト環境を構築する。
* **ターゲットデータ**: 単一の2Dモノクロ画像ファイル（例: PNG, JPEG, または汎用的なバイナリデータ）。DICOM固有の解析は不要とする。
* **技術スタック**:
    * **フロントエンド**: Next.js (TypeScript, App Router)
    * **高性能処理コア**: Rust (WebAssembly)
    * **画像表示/操作**: HTML Canvas API、またはシンプルな画像処理ライブラリ（`fabric.js`など）を使用。**VTK.jsは一旦除外**し、シンプルな2D画像表示に限定する。

## 2. 実装環境と制約

1.  **フレームワーク**: Next.js (TypeScript) を使用し、App Router (`app/`) 構成とする。
2.  **Wasm連携**: Rust WasmのビルドとNext.jsからの呼び出し設定（`wasm-bindgen`）を必須とする。
3.  **画像処理**: DICOMではなく汎用的な2D画像データを扱うため、**VTK.jsの使用は除外**し、React/TypeScriptで実装可能なシンプルな画像表示・操作に切り替える。
4.  **動作環境**: コンポーネントはすべて **'use client'** を指定し、クライアントサイドでのみ動作するように実装する。

## 3. 機能要件 (F: Functional Requirement) (プロトタイプ範囲)

以下の機能要件をすべて満たすプロトタイプコードを生成してください。

### F-1: 2Dモノクロ画像入力と表示

| 項目 | 詳細 | 担当技術 |
| :--- | :--- | :--- |
| **ファイル入力** | ユーザー操作により、**単一の2D画像ファイル**（PNG/JPEG等を想定）をローカルPCから選択・読み込みできること。`input type="file"`を使用する。 | Next.js (TS) |
| **ファイルリーダー** | 選択されたファイルを `FileReader` を使って読み込み、画像データを取得すること。 | Next.js (TS) |
| **画像表示** | 読み込んだ画像をHTML Canvas、またはシンプルな `<img>` タグを使用して、画面に表示すること。**モノクロ画像**として表示可能であること（カラーの場合はグレースケール変換を想定）。 | Next.js (TS) |
| **Wasm連携テスト** | ファイル読み込み後、**Rust Wasmモジュール（`greet_wasm()`）を呼び出し**、結果を画面に表示して連携が成功したことを確認する。 | Next.js (TS) & Rust Wasm |

### F-2: 画像操作機能（基本）

| 項目 | 詳細 | 担当技術 |
| :--- | :--- | :--- |
| **UI構造** | ファイル入力エリア、Wasmテスト結果表示エリア、画像表示エリアを配置する。 | Next.js (TS) |
| **ユーザー操作開始**| 画像が表示された後、ユーザーがマウス操作（例: ドラッグで移動、ホイールでズーム）を開始できる状態になっていること。 | Next.js (TS) |
| **パン/ズーム** | 表示された画像に対し、マウス操作による**パン（移動）**と**ズーム（拡大・縮小）**ができること。 | Next.js (TS) / Canvas API またはシンプルライブラリ |

## 4. コーディング要件 (Rust Wasm)

### R-1: Rust Wasm モジュール

* **ファイル**: `src/lib.rs`
* **目的**: Next.jsのTypeScriptから呼び出されるWasm連携の確認テスト。
* **関数**: `greet_wasm`
    * **引数**: なし
    * **戻り値**: TypeScript/JavaScriptに `String` で **"Wasm module is ready and linked!"** を返すこと。

### R-2: Wasm 設定ファイル

* `Cargo.toml` に `wasm-bindgen` をターゲットとしたライブラリ設定を含めること。
