# 📐 TMJ-Diagnosis 機能仕様書: セグメンテーションとベクター化

## 1. プロジェクト・機能概要

| 項目 | 詳細 |
| :--- | :--- |
| **プロジェクト名** | **TMJ-Diagnosis** |
| **機能の目的** | クライアント側で読み込まれた2Dモノクロ画像から、顎関節の骨構造（下顎頭・関節窩）を自動抽出し、編集可能なベクターパスとしてフロントエンドに出力する。 |
| **前提** | F-1で画像ファイルが読み込まれ、ピクセルデータがメモリ上に存在していること。Wasm連携が完了していること。 |
| **技術スタック** | **Next.js (TS)** および **Rust (WebAssembly)** |

***

## 2. 機能要件 (F: Functional Requirement)

このステップで実装する主要な機能は以下の通りです。

#### F-3: 画像処理とベクター抽出（Rust Wasm）

| 項目 | 詳細 | 担当技術 |
| :--- | :--- | :--- |
| **F-3.1: 入力データ** | フロントエンド（TS）から、読み込まれた2Dモノクロ画像の**ピクセルデータ**（例：`Uint8Array`）と、画像の**幅・高さ**（`u32`）を受け取る。 | Rust Wasm |
| **F-3.2: 自動抽出（Segmentation）** | 入力ピクセルデータに対し、**画像処理アルゴリズム**（閾値処理、エッジ検出、形態学処理などを想定）を適用し、**下顎頭**と**関節窩**の領域を自動的に特定する。 | Rust Wasm (`image`, `imageproc` クレートなどを想定) |
| **F-3.3: 輪郭抽出** | 特定された領域のピクセル境界を追跡し、その座標を抽出する。 | Rust Wasm |
| **F-3.4: ベクター化** | 抽出した座標リストを、点の数を最適化した**滑らかなベクターパス**に変換する。 | Rust Wasm |
| **F-3.5: 出力** | 下顎頭と関節窩それぞれの**ベクターパス情報**（座標配列とその識別子）を**JSON文字列**で構造化し、フロントエンド（TypeScript）にまとめて出力する。 | Rust Wasm (`wasm-bindgen`) |

#### F-4: フロントエンドでの描画と編集（Next.js/TS）

| 項目 | 詳細 | 担当技術 |
| :--- | :--- | :--- |
| **F-4.1: Wasm呼び出し** | ユーザーが「自動抽出」ボタンを押すなどトリガーで、画像データとメタデータをRust Wasm関数に渡し、処理結果（JSON文字列）を受け取る。 | Next.js (TS) |
| **F-4.2: ベクター描画ライブラリ** | `fabric.js` や `Konva.js` などのライブラリを導入し、Canvas上に描画環境を構築する。 | Next.js (TS) |
| **F-4.3: 描画** | Wasmから受け取ったJSONデータを解析し、下顎頭と関節窩のアウトラインを**編集可能なパスオブジェクト**としてCanvas上に描画する。 | Next.js (TS) / 描画ライブラリ |
| **F-4.4: パス編集** | 描画されたアウトラインは、ユーザーが**アンカーポイントの移動や追加・削除**などにより、形状を自由に修正できること。 | Next.js (TS) / 描画ライブラリ |
| **F-4.5: 確定** | 編集内容を確定（ロック）し、次の計測ステップに進む準備として、確定したアウトラインの最終座標データを保持する機能。 | Next.js (TS) |

## 3. コーディング要件 (Rust Wasm 拡張)

#### R-3: Rust Wasm モジュール拡張

* **ファイル**: `src/lib.rs` を拡張。
* **関数**: `process_image_for_tmj(data: Box<[u8]>, width: u32, height: u32) -> String` を新設する。
* **入出力仕様**:
    * **入力**: `data` (ピクセルデータ), `width` (幅), `height` (高さ)
    * **出力**: `String` (以下の構造を持つJSON文字列)
        ```json
        {
          "condyle": [ [x1, y1], [x2, y2], ... ],
          "fossa": [ [x1, y1], [x2, y2], ... ]
        }
        ```

#### R-4: フロントエンド連携の強化

* `app/page.tsx` に「自動抽出実行」ボタンと、ベクターを描画・編集するためのCanvasコンポーネントを追加する。
* RustからのJSONを解析し、`fabric.js`などのパスオブジェクトに変換する処理を実装する。
